# Jogo da Forca - 2 Jogadores

Projeto simples em Java desenvolvido para funcionar no Eclipse IDE.

O jogo funciona com dois jogadores. O Jogador 1 escolhe uma palavra com exatamente 5 letras e o Jogador 2 tenta descobrir a palavra informando uma letra por vez.

## Funcionamento

- A palavra deve ter exatamente 5 letras.
- O Jogador 1 escolhe a palavra no início da partida.
- O Jogador 2 tenta descobrir as letras usando as janelas do `JOptionPane`.
- O limite é de 6 erros.
- Se todas as letras forem descobertas, o Jogador 2 vence.
- Se o limite de erros for atingido, o Jogador 1 vence.

## Estrutura

O código principal está localizado em:

`src/atividadejogodaforca/main.java`

O codigo compilado é gerado em:

`bin/atividadejogodaforca/main.class`
